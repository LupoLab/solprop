# Results and interpretation

quantities. Begin with their units and normalisation, then learn how to save and
reopen output, select statistics, and process or plot the result. The
[first simulation](../../introduction/lessons/plot_01_rdw.rst) introduces the main plotting
workflow; the [analysis tutorial](../../auto_tutorials/basics/plot_03_analysing_a_run.rst)
provides a focused example. Where solprop's output, statistics, processing or plots
differ from Luna.jl's, the differences are listed in
