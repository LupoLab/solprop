# Design and workflows

Design tools estimate useful parameters before a propagation. Offline optics
and compressors analyse or modify its output. Scans then repeat a calculation
over a controlled set of parameters. These chapters explain the workflows and
their assumptions; the [examples](../../examples/index.md) show them in context.
