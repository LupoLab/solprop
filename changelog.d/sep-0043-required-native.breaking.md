`solprop-native` is a required dependency, with no extra: `pip install solprop` installs it, and solprop is supported where it installs ([SEP 43](docs/dev/seps/sep-0043-retire-numba-cpu.md)). On any other platform, including Intel macOS, ppc64le, musl and macOS before 14, the installer reports that no matching distribution exists; the installation page explains that and how to report a platform. The `native` extra is gone.
