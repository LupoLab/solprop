On a small team whose LLVM OpenMP runtime spins within native calls (a default run on an Apple M5 Max's six top-tier cores), the native backend threads smaller passes: every size threshold is divided by 16, since a parallel region there costs about a microsecond. On an Apple M5 Max at six threads the Raman GNLSE ran 0.70 of its time and the comb-to-continuum 0.91, none slower (ADR-073). Wider teams and Linux builds with GNU's runtime keep the previous thresholds, which measured faster there.
