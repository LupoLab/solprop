The native backend refuses the benchmark-only Adams comparison family, `ComparisonMultistep`, by name and before it allocates anything, on CPU and device builds: PECE, explicit Adams–Bashforth (`corrector="none"`), the matched pairs (`corrector_order = order`) and the one-order-higher PEC variant (`corrector="pec", corrector_order=order + 1`) alike. They ran on solprop's Python march, or for the PEC variant on the transitional native bridge; they are now the NumPy reference's alone (SEP 47 section 6.3), so run them with `backend="numpy_ref"`, or use `Multistep()`, the selected method, on native. The native bridge's copy of the general Adams path and its Hermite dense interpolant are removed with them.
