Snapshots now work with interpolated planes (`interpolate_planes=True`), which they refused before: a requested snapshot waits for the next accepted endpoint after every plane its step crossed has been saved, so its running checkpoint is a state the march passed through, which `resume=True` continues without `resume="interpolated"`, saving each later plane once. The native execution session (SEP 47's prototype, selected by tests and the benchmark harness) now interpolates planes itself, for Adams and the embedded Runge-Kutta tableau alike, where the state lives: no stage or field crosses to the host but the exported plane ([SEP 47](docs/dev/seps/sep-0047-run-ownership.md)).
