The native backend's private host-march switches are retired as production modes ([SEP 47](docs/dev/seps/sep-0047-run-ownership.md) §6.3): the environment variables `SOLPROP_ADAMS_MARCH`, `SOLPROP_RK_MARCH` and `SOLPROP_RK_ROWS` are no longer read, and `NativeBackend` no longer takes an `adams_march` keyword. They selected solprop's Python march on the native engine for A/B comparisons. The test interface that replaced them is retired too, with `benchmarks.adams_host`'s `--host-march` and `--host-stages` arms: every native run is the native execution session's, and the identical-input decision traces and the comparisons with `numpy_ref` in the test suite serve their diagnostic purpose. A problem whose operator or prefactor representation the native stage tables cannot read, which no built-in configuration produces, is now refused by name when the backend is built instead of being stepped with stage rows formed on the host.
