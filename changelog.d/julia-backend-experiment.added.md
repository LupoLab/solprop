An experimental `julia` backend (`backend="julia"`, the `julia` extra and a Julia 1.13 runtime prepared by `julia/bootstrap.py`) runs the scalar modal capillary, mode-averaged, radial, Cartesian and line routes on a CPU, or on an NVIDIA GPU with `SOLPROP_JULIA_DEVICE=cuda`, in binary64 or binary32, from one Julia source. It is an experiment, not a supported backend: `julia/STATUS.md` lists what it runs and refuses, and the [manual page](docs/guide/performance/julia.md) how to try it.
