`solprop.output.resume` is renamed `solprop.output.read_resume_state` (also in `solprop.output.hdf5`): it reads a file's resumable state into a `ResumeState` and continues nothing, which `resume=True` on a run or `solprop resume` does. Replace `from solprop.output import resume` and `resume(path)` with `read_resume_state`; the old name is gone.
