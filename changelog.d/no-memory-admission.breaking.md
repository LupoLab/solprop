solprop no longer estimates a run's memory or checks it against a budget before allocating (ADR-065). `memory_budget=`, `SOLPROP_MEMORY_BUDGET`, `estimate_memory`, `estimate_guide_memory`, `solprop.driver.memory`, `MemoryBudgetError` and `MemoryBudgetWarning` are gone. A run that doesn't fit now fails with `MemoryError`, or is killed by the kernel or a scheduler. Scan workers and TDSE's `memory_limit` are still bounded; going over that limit raises `DriverError`, and it now covers atomic storage alone. Drop `memory_budget=` from calls and `SOLPROP_MEMORY_BUDGET` from job scripts; bound memory with the scheduler instead.
