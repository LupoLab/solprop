`modes.base.zdw` now searches the sampled sign of `beta_2` and keeps a sign change only where the analytic group delay has a resolved extremum, so a gas resonance's poles are no longer read as zeros, and a window whose ends agree in sign no longer hides the zeros inside it. Several zeros in the window raise `ModeError` naming them, where an arbitrary one was returned or `NoZeroDispersionError` raised; the new `near=` reference wavelength picks the nearest zero that no resonance separates from it. `stats.zdw` takes `near=` too, and the `zdw` run statistic passes the grid's reference wavelength, so a krypton capillary whose band reaches its 120 nm lines records its 770.5 nm zero instead of `nan` (#157, #527).
