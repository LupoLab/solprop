Output files are written in output schema 3. A file's march snapshot (`/march_snapshot`) stores its `state` as `(n_modes, n_pol, n_omega)` and its engine `rows` as `(n_slots, n_modes, n_pol, n_omega)`, without the leading axis of one they kept before, and the plane-reference record (`RunMetadata.reference`) has no `basis` entry: a plane's basis is derived when it is read. Saved fields, statistics and the rest of the run record are laid out as before. A file or scan written by 0.2.0 (output schema 2) is refused wherever it is opened, read or resumed, and the refusal names the file and the release that wrote it: read, resume or continue it with solprop 0.2.x, and a 0.1.0 file (schema 1) with solprop 0.1.x.
