Output files written by development builds between 0.1.0 and 0.2.0 in forms no release wrote are no longer read specially: a march snapshot without a `history_key` is now ignored with a warning and the Adams history starts afresh, and `MarchSnapshot.history_key` is required. Read such a development file with the build that wrote it; a file of output schema 2, which 0.2.0 wrote, is read with solprop 0.2.x.
