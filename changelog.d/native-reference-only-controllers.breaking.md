The native backend refuses a `PIController` subclass that overrides one of its decisions or its norm (`scale`, `accepts`, `propose`, `rejection_factor`, `start_factor` or `equivalent_norm`), by name and before it allocates anything, on CPU and device builds, for every method. Such a controller ran on the transitional native bridge, its Python loop with a `HostMarchWarning` where it overrode the norm's scale; it is now a reference-only experiment (SEP 47 section 6.3), so run it with `backend="numpy_ref"`, or use `PIController` itself on native.
