Runs on the native backend's CPU build now go through the native execution session whenever it admits the run ([SEP 47](docs/dev/seps/sep-0047-run-ownership.md)), with the same steps, fields, statistics, step records and call ledgers as before. The session also runs resumed runs, carrying the Adams history and the call ledgers, the input and modified noise models, the boundary monitor (including a free-space run's transverse edge), dense output and the low-storage replay, and it exports the Adams history beside each saved plane and checkpoint. A signal during a run is still handled once the native call returns, within 256 attempts or 0.1 s; the run's checkpoint then includes every attempt made. Some runs still use the backend's own march, as before: comparison methods and methods other than Adams and the embedded Runge-Kutta tableaux; controllers that override `PIController`'s methods; TDSE responses; the input noise beside a transverse edge; a noise model on a propagator stored as a z table; marches the backend steps on the host (a coupled flow off its eigenbasis route or wider than 16 channels, or low-storage stage rows the host forms); and the on-axis plasma statistics, which the host still finishes. A spatial run's `beam_radius` and `fwhm_r` are now finished natively, so the default statistics of a radial or free-space run no longer leave the native session, and so is `zdw`, read from a table of each mode's zero-dispersion wavelength along z made once before the run (exact for a mode that does not vary along z, otherwise within 1e-6 of the wavelength, with the measured error in the run's execution record under `statistics_tables`); the native backend records `nan` where the band holds no zero, as `numpy_ref` does, instead of raising. The native backend refuses by name the metric statistics of a general modal basis whose metric varies inside one of its intervals. Statistics a problem does not carry are refused by name before the run starts, on every backend, instead of at the first saved plane: a modal statistic such as `omega0` on a spatial run, a spatial statistic such as `beam_radius` or `absorbed_power` on a modal run (where `numpy_ref` used to return the peak ionisation rate as `absorbed_power`), the plasma integration diagnostics without a field-grid plasma column, and the electron density or peak ionisation rate without a plasma response. A `Batch` scan's group refuses noise models in the native group session and runs them on the lockstep batch.
