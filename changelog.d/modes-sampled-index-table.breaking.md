The index table that `solprop.modes.tabulated.sample_index_table` returns, and that each channel of a `ModalGuide` built from a provider carries, is now the public `solprop.modes.tabulated.SampledIndexTable` (it was the private `_SampledIndexTable`), and the provider-table sampling it comes from moved from `solprop.translate.modal_tables` to the new `solprop.modes.tables` (`sample_modal_table`, `sample_provider_table`, `DenseModalTable` and the rest); a moving guide's path sampling moved from `solprop.translate.modal_path` to `solprop.modes.path`. Import those names from their new modules. The table's class name is part of a run's configuration record, so a general modal run, or any run whose modes hold such a table, recorded before this change cannot be resumed by a later version: run it again.
