The default boundary check no longer brings a native run's state to the host. Without a requested collar, the transverse edge is read where the state lives and only numbers cross, so a field-free run on a device copies no state at all, and on the CPU a free-space Kerr beam's check costs less. A read now covers every frequency plane: `solprop.transverse_monitor.READ_RESOLUTION` is gone, and a share can read higher than before by at most `1e-9` of the launch energy at the default budget. A resumed run with a requested collar now restores its current, baselines and peaks, so it no longer judges against zero. (SEP 44, #385, #396, #512)
