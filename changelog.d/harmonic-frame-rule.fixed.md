Fixed the frame of an envelope run beside a third harmonic. Every route now chooses it by one rule, `solprop.translate.responses.declares_harmonic_carrier`, which translation checks against the compiled harmonic carrier: only a Kerr or dispersive Kerr response with `thg=True` keeps `beta_0`, so a Raman response's `thg`, which an envelope grid ignores, no longer keeps it while the run record said it was removed. An explicit `Frame(..., subtract_beta0=True)` beside a third-harmonic term on an envelope grid is now refused with a `TranslationError` instead of driving the harmonic with a spurious phase mismatch (#77).
