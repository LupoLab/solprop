A run record's numeric arrays of more than 4096 elements are now hashed by their bytes and stored beside its JSON: `/meta/json` holds a reference, and `/meta/arrays/<digest>` the array, or `/record_arrays/<digest>` in a scan, shared between points. The text of a 512² Cartesian run's record falls from about 23 MB to under 1 MB, and the first configuration hash from seconds to milliseconds, with every array still readable. `RunMetadata.from_json` takes the arrays as `arrays=`, and `RunMetadata.record_arrays` returns them. A file written before this still reads, its arrays inline. A noise realisation moves too ([#309](https://github.com/LupoLab/solprop/issues/309)).
